# Mine Picker

A Java implementation of the classic Minesweeper game, built for the CodeGym game task [Mine Picker](https://codegym.cc/projects/games/com.codegym.games.minesweeper).

![Mine Picker](https://cdn.codegym.cc/images/system/3ae9ee71-f342-498b-a1e9-44a524ea954c/original.png)

## About The Project

Reveal all the unmined squares of the board without hitting a mine. Revealing a square shows how many mines are adjacent to it; use those numbers to deduce which squares are safe and which should be marked as mined.

From the author's notes: this project was made from scratch following the task's specific instructions, with several elements (such as the game engine) provided by the course.

The original README's changelog:

- V1.01: colors modified; grid extended to 18x18.
